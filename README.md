Курсова робота з дисципліни «Системне програмування».

## Можливості

**Розклад**
- Перегляд розкладу за **групою, викладачем або аудиторією**
- Цикл тижнів: щотижня, чисельник, знаменник, 3-й та 4-й тиждень, фільтр за тижнем
- Автоматична перевірка конфліктів викладача, аудиторії та групи
- Редагування пари **подвійним кліком**; подвійний клік по порожній комірці додає пару
- Автопідбір вільної аудиторії
- Пошук і фільтр за викладачем, предметом, аудиторією
- Підсвітка сьогоднішнього дня та поточної пари
- Пошук і підсвітка «вікон» у розкладі групи чи викладача

**Звіти**
- Навантаження викладачів: пар і годин на тиждень, кількість вікон, діаграма
- Завантаженість аудиторій у відсотках
- Звіт про конфлікти для всієї бази

**Дані**
- Керування групами, предметами (з кольором), викладачами, аудиторіями та розкладом дзвінків
- Імпорт та експорт довідників в Excel і CSV
- Імпорт розкладу з Excel/CSV з попереднім переглядом
- Резервна копія та відновлення бази даних

**Експорт і друк**
- Експорт розкладу у PDF, Excel (.xlsx) та CSV
- Друк із попереднім переглядом; розклади всіх груп одним PDF

**Інтерфейс**
- Теми: світла, темна, системна

## Завантаження

Готовий інсталятор для Windows та портативний ZIP-архів знаходяться на сторінці
[Releases](../../releases). Встановлення Qt не потрібне.

## Збірка з вихідного коду

**Потрібно:** Qt 6.5+ (перевірено на 6.12), CMake 3.19+, компілятор з підтримкою C++17,
`git` та інтернет при першому налаштуванні (завантажується бібліотека QXlsx).

**Qt Creator:** відкрийте `CMakeLists.txt`, оберіть комплект і натисніть **Ctrl+B**.

**Командний рядок:**

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH=<шлях до Qt>
cmake --build build --parallel
```

Шлях до проєкту краще без пробілів та спецсимволів (`!`, `(`, `)`).

### Інсталятор для Windows

1. Встановіть [NSIS](https://nsis.sourceforge.io) (потрібен лише для `.exe`-інсталятора).
2. У файлі `deploy/deploy_windows.bat` вкажіть шляхи до Qt, компілятора, CMake/Ninja та NSIS.
3. Запустіть `deploy/deploy_windows.bat`.

Результат: `build-release/SmartSchedule-<версія>-Windows.zip` та `.exe`; портативна версія лежить у теці `dist/bin`.

## Формат імпорту розкладу

Файл `.xlsx` або `.csv`; для Excel дані беруться з аркуша **«Дані»**. Найпростіше: експортуйте розклад із програми
(*Файл → Експорт розкладу всіх груп*), відредагуйте та імпортуйте назад.

| Група | День | Пара | Тиждень | Предмет | Викладач | Аудиторія |
|---|---|---|---|---|---|---|
| КІ-106 | Понеділок | 1 | Постійно (Кожного тижня) | Бази даних | Марцюк О. В. | 201 |

- **День:** назва (Понеділок … П'ятниця) або число 1–5
- **Тиждень:** `Постійно`, або число 1–4 (наприклад, `1-й тиждень (Чисельник)`)

## Структура проєкту

```
SmartSchedule/
├── CMakeLists.txt
├── main.cpp
├── databasemanager.*        # SQLite, конфлікти, резервні копії
├── mainwindow.*             # головне вікно, меню, експорт, друк
├── schedulegrid.*           # таблиця розкладу (групи / викладачі / аудиторії)
├── schedulefilter.h         # режими перегляду та фільтр
├── scheduleanalysis.h       # вікна, конфлікти, навантаження, завантаженість
├── filterbar.*              # панель пошуку та фільтрів
├── addentrydialog.*         # додавання та редагування пари
├── referencedialog.*        # довідники (універсальний діалог)
├── bellsdialog.*            # розклад дзвінків
├── workloaddialog.*         # навантаження викладачів, діаграма
├── roomloaddialog.*         # завантаженість аудиторій
├── entityscheduledialog.*   # розклад викладача / аудиторії
├── conflictreportdialog.*   # звіт про конфлікти
├── scheduleimporter.*       # імпорт розкладу
├── importscheduledialog.*   # діалог імпорту
├── schedulehtml.*           # HTML для PDF та друку
├── csvutils.h, tablefile.h  # CSV та Excel
├── theme.*                  # теми оформлення
├── cmake/Packaging.cmake    # CPack (NSIS, ZIP)
└── deploy/deploy_windows.bat
```

## Дані програми

База даних `schedule.db` створюється автоматично при першому запуску:
`%APPDATA%/SmartSchedule/` (Windows). Для переносу даних використовуйте *Файл → Резервна копія бази даних*.
