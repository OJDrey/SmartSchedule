# Протокол тестування

Робота: SmartSchedule. Версія: 1.5.0. Файл тестів: `tests/tst_smartschedule.cpp`.

Середовище виконання: Ubuntu 24.04, GCC 13.2, Qt 6.4.2, SQLite 3.45, CMake 3.28, QT_QPA_PLATFORM=offscreen.

Повторний запуск у цільовому середовищі: Windows 11, MinGW GCC 15.1, Qt 6.12.0, Qt Creator (07.11.2026, 18:25). Результат: 25 пройдено (23 тести та службові initTestCase і cleanupTestCase), 0 не пройдено, 0 пропущено, 1795 мс.
